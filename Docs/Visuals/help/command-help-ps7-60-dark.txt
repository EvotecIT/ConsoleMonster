Get-ConsoleCapability
Shows what ConsoleMonster detected about the current
terminal.

Syntax
  Get-ConsoleCapability [-Refresh] [<CommonParameters>]

Description
  Shows what ConsoleMonster detected about the current
  terminal.

  Returns the terminal profile: kind, mode (Interactive,
  Stream, Plain), colour depth, glyph tier, size, VT
  support, console font and the reasons behind each
  decision. -Refresh detects again (after a resize or font
  change).

Remarks
  Get-Help Get-ConsoleCapability -Examples / -Detailed /
  -Full
