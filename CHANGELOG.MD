### Unreleased - the everyday path
#### What's new
- `Compare-ConsoleText` compares strings or files with line numbers, word highlights and collapsed unchanged ranges. It uses side-by-side output from 120 columns, inline output below that, `-Context`, `-IgnoreWhitespace` and plain unified text with `-AsUnified`. The shared text engine uses linear auxiliary memory and bounded alignment work.
- `Enable-ConsoleFormatting -Feature ReadLine` themes loaded PSReadLine syntax, selection and available inline predictions; `Streams` also styles native progress while preserving its view. Shared native preferences follow the latest applied installation across runspaces; the last owner restores the first exact baseline, including after user edits. ReadLine is included in All. All keeps Write-* cmdlets native and excludes the legacy Progress alias feature.
- Windows-style form command lines preserve quoted paths with trailing backslashes and values containing embedded quotes using native Windows argument-quoting rules.
- Hosted-service dashboard durations measure each service's lifetime with a monotonic clock and freeze at its own stop, completion or failure, preserving the result through host shutdown.
- `Enable-ConsoleFormatting -Feature Streams` colors native warning, verbose and debug messages with the active theme, plus errors on PowerShell 7.2+. Included in `All`; disabling or removing the module restores the original settings. PowerShell keeps its stream commands, prefixes, preferences, redirection and transcripts.
- One value-shaping layer for every command (`ConsoleMonster.Values`): columns come from `-Property`, a registered view, PowerShell's own table view, the default display set or a fallback; dictionaries are records, arrays are joined in cells, records are titled like `pwsh (90836)`, secure strings are masked, slow or hanging getters are bounded and marked. `Register-ConsoleView -Shaper` and `ValueShaper.Register` add your own.
- Format-Console output reaches every consumer: piped commands get plain lines, PowerShell 7.2+ captures a command typed at the prompt (`$x =`, `>`, `-OutVariable`, transcripts), and `-AsString` works everywhere. Widgets and renderings draw themselves at `Out-Default` (`ConsoleMonster.format.ps1xml`, generated from the widget types). `Show-Console` follows the same model.
- `-GroupBy` headings are labelled rules with counts ("2 of 3" when `-Top` cuts a group) and the group count in the footer; the grouped column is left out (`-ShowGroupColumn`), groups are sorted (`-NoSort`).
- Numbers in a column share the decimals the column needs; short values never wrap; long text stops at three lines (`-Wrap`, `Table.WrapLines`, `TableColumn.Unlimited`).
- One status vocabulary with PowerShell's words (Success, Information, Warning, Error, Failed, Verbose, Debug, Skipped) for `-Status`, `Write-ConsoleLog -Level` and status columns, with markers in every command and in log regions.
- One date format everywhere (`yyyy-MM-dd HH:mm`, local time, culture-independent); numbers follow the culture.
- `Format-ConsoleTable -View Record`, `New-ConsolePanel -Content` with any object, bar chart thresholds (`-Warning`, `-Critical`), check marks for finished progress, a shorter error view, "not compared" in change summaries, shorter default trees for wide objects.
- `Enable-ConsoleFormatting -ProfileSnippet`; built-in views for Get-Command, Get-Module, Get-WinEvent, Get-NetIPAddress and Get-Volume; the `fct` and `fcl` aliases; `Example-LoginOverview.ps1`.
- Widgets for runs of many items: `CellMap` (one cell per item, a symbol per state in every tier, an active window that follows the running cell), `SummaryBar` (bar, done of total, percentage, time left, counters with zeros dimmed), `ActivityList` ids and elapsed time, `Lanes` options (`DimPending`, `BoldActive`, `ShowRunningCount`, `CollapseWhen`) and `FooterBar.Segments`. The test-run view uses them: the summary line, the files with skipped ones folded, the outcome of every test, the running test with its time, then the failures.
- `Watch-Console { … } [-Interval 2] [-Count n] [-Differences]` reruns a script block and shows its latest output (with its errors and warnings under it, changed cells marked with `-Differences`); a failed run shows its error and the watch goes on. Piped on or without a console, it prints every run.
- `ForEach-ConsoleItem` (`Invoke-ConsoleRun`) runs a script block for every input item, one at a time in the caller's scope or with `-Parallel -ThrottleLimit n` in runspaces (`$using:name`, `-TimeoutSeconds`, Ctrl+C), on Windows PowerShell 5.1 and PowerShell 7. A live view shows the summary line, a cell per item, the running items and the failures; the output comes in input order (`-Unordered` for completion order) and failures are error records. Without a console it prints a line per item and a summary. `ConsoleRun.ForEachAsync` and `RunMonitor` do the same from C#.
- `Enable-ConsoleFormatting -Feature Output, ErrorView, Progress` (the Progress alias is excluded from `All`): errors that reach the console use ConsoleMonster's error view (`DetailedView` adds the stack, `CategoryView` keeps PowerShell's), and `Write-Progress` becomes an alias of the new `Write-ConsoleProgress`, drawn as an activity area below the cursor that steps over output, warnings and `Write-Host` lines written in between. `Disable-ConsoleFormatting [-Feature]` turns parts off and puts back a user's own `Out-Default` function or `Write-Progress` alias replaced with `-Force`; `$ErrorView` is never changed. `InlineArea` is the C# side of the progress area.
- `Show-ConsoleHelp <command>` shows a command's help from Get-Help: synopsis, syntax with parameter names, value types and optional parts told apart, a parameter table (type, required, position, pipeline input, default, description), highlighted examples, inputs, outputs, notes and links; cmdlets, functions and scripts with comment-based help on 5.1 and 7, plain lines through a pager. `HelpView` and `HelpTopic` are the C# side.
- New package `ConsoleMonster.Extensions.Logging`: an `ILoggerProvider` (`logging.AddConsoleMonster()`) with the level tags and colours of `Write-ConsoleLog`, a timestamp format, short or full categories, scopes, event ids and exceptions; entries go into a running dashboard's log region and print as plain lines when redirected. Depends only on Microsoft.Extensions.Logging.Abstractions.
- New package `ConsoleMonster.Hosting`: `services.AddConsoleDashboard()` shows the generic host's hosted services (waiting, starting, running, stopping, stopped, completed, failed, with how long and the failure message), entries reported through `IConsoleDashboard` and the log, and draws nothing when redirected, in CI or as a service. Depends only on Microsoft.Extensions.Hosting.Abstractions.
- New package `ConsoleMonster.Templates`: `dotnet new consolemonster` creates an app with a menu, a status report, logging, the host dashboard and native AOT publishing.
- `LogTags` exposes the level tags and styles of the log region. `Docs/Proposals/Command-Line-Layer.md` lays out the options for a command-line layer.
- Renderings (what `Format-Console*` writes on PowerShell 7.2+) are out of band at `Out-Default`, so they show on their own also between the rows of another table; widgets keep `Format-List *`.
- Linux and macOS: locale-aware glyphs (LC_ALL, LC_CTYPE, LANG), no cursor queries on Unix, portable display paths; CI on Linux for every push and macOS for pull requests.
#### Behaviour changes
- A single object in `Format-ConsoleTable` stays a one-row table, as with `Format-Table` (a single dictionary is still shown as a record); use `-View Record` for labelled fields.
- `TableColumn.MaxLines = 0` now follows `Table.WrapLines` (3 by default) instead of meaning no limit; use `TableColumn.Unlimited` (in PowerShell column hashtables `MaxLines = 0` keeps meaning no limit).
- `Show-ConsoleGrid` without an interactive console prints the rows as a table with a warning and returns nothing; a script that caught the old error with `-Mode Full` or `Line` now gets the warning (`-Mode None` still fails).
- `New-ConsolePanel` script blocks show their stray output (the number `ArrayList.Add` returns, a `$true`) instead of dropping it.
- Inside scripts and functions, and on Windows PowerShell 5.1, Format-Console commands draw on the screen as before; use `-AsString` to capture there.
- Activity lists (Write-Progress under `Use-ConsoleProgress`, dashboards) show each activity's elapsed time on the right (`ActivityList.ShowElapsed`), and an activity without a percentage spins instead of showing a waiting circle.
- The test-run view's header keeps the title, status and clock; the counts moved to the summary line under it.
- Three equivalent C# styles on every widget. Object initializers stay the model. A build-time Roslyn source generator (`ConsoleMonster.Generators`, compiled into `ConsoleMonster.dll`, not shipped as an analyzer) adds a `With...` method for every settable property (`WithX()` sets a bool to true, `WithX(o => ...)` configures option objects) and `Add...` methods for every collection on all widgets and their option types. Typed tables come from `Table.For(items)` / `Table<T>`, with `.Column(s => s.Name, c => ...)` taking its header from the expression, property columns when none are given, and `Refresh()`; `Table.AutoTotals` and `.WithTotals()` sum the numeric columns. The `ConsoleMonster.Ui` factories (`Rows`, `Columns`, `Grid`, `Panel`, `Fill`, `Fixed`, `Table`, `KeyValue`, `Text`, `Rule`, `Sparkline`, `Lanes`, `Progress`, `Status`, `Tree`, `Node`, `Dashboard`) are for `using static`. A coverage test fails on a property without its fluent method, and a golden test shows the three styles render the same screen. `Table` is no longer sealed (only `Table<T>` derives from it).
- Replay shows one frame: a recorded `Dashboard`'s own header and footer are not replayed, and its title (the default run name in `Show-ConsoleReplay`), subtitle and status show in the player's header.
- Redirected dashboards no longer record their own output again: the log lines that the PowerShell host wrote back through `Console.Out` came back as `$log` "out" events about every 60 ms (a bug that predates 2.0's replay work). `LiveSession.SuspendCapture()` lets a host write a session's output without capturing it.
- Change tables list an added or removed object's compared properties on their own lines (`ObjectChange.Values`), up to `ChangeView.MaxProperties` (6), then "+N more" with `ChangeView.MoreHint` ("-PassThru or -View SideBySide" from the cmdlets); the side-by-side view lists them all.
- The HTML recording player is one native asset (`ConsoleExporter.PlayerScript`, `ConsoleExporter.PlayerStyles`, embedded `player.js` / `player.css`) with a data format (`Recording.ExportPlayerData`, `Export-ConsoleRecording -Format PlayerData` or `-Destination *.json`) and a `data-cm-recording` contract, so sites include the script once for many players; it rewrites only changed rows, wakes at the recording's frame rate, updates the clock and position once a second, pauses off-screen and in hidden tabs, autoplays one player per page and none under reduced motion (headless Chromium, 120x36 busy recording: main thread 4.7% to 2.1%, renderer CPU 9.8% to 4.1%, 0% off-screen, no long tasks).
- Rewinding runs: `Show-ConsoleReplay` and `ReplayPlayer` (play/pause, speed, frame stepping, a timeline with markers, jumps to markers, failures, warnings and log entries, log search; full screen or inline; markers printed as lines without an interactive console), `ReplayMarker.From`, `LiveSession.Mark` / `LiveSession.MarkerTarget` (`Send-ConsoleEvent -Target '$marker'`), opt-in automatic recording (`LiveSessionOptions.AutoRecord`, `AutoRecordMaxBytes`, `AutoRecordFolder`, `RecordingName`, `DefaultRecordingFolder`, `LiveSession.RecordingPath`, `Start-ConsoleDashboard -AutoRecord`), and region swaps recorded as pictures (markup snapshots of the new content and of later changes inside it) so they replay faithfully.
- Object comparison and the what-if pattern: `ObjectDiff`, `ChangeSet`, `ObjectChange`, `PropertyChange`, `DiffOptions`, `ChangeView` (summary, table, side by side, unified, line diffs) and `ChangePreview` (typed confirmation for removals); `Compare-ConsoleObject` (with `-PassThru`) and `Show-ConsoleChanges` (honours `-WhatIf` and `-Confirm:$false`, returns the decision).
- Identifier columns (Id, ProcessId, PID, ports, Index, Year...) are no longer grouped with thousands separators or totalled: `IdentifierPresenter`, `CellPresenters.Identifier` and the `Identifier` column option.
- Header bars keep the title on narrow windows; the right side gives way (free text, then the clock, then the status is shortened and dropped).
- `Terminal.WriteMarkup` / `Write-ConsoleMarkup` wrap long lines at word boundaries in interactive output (redirected, CI and plain output keep whole lines).
- Empty text keeps the existing value wherever null does (phase, status and lane labels and details, spinner and activity text), so `$null` passed from PowerShell no longer blanks a label.
- Terminal progress indicator (OSC 9;4): `TaskbarProgress`, `ITaskbarProgressSource` on progress bars, lanes, spinners, activity lists, dashboards and the test-run view; live sessions, the status line and `Terminal.Status` drive it and clear it at the end, on Ctrl+C and on exit; only in Windows Terminal or ConEmu, never in CI, redirected or plain output; `CONSOLEMONSTER_TASKBAR=0`, `LiveSessionOptions.TaskbarProgress` and an opt-in bell (`NotifyOnFinish`).
- `Show-Console` and `ConsoleView` (`Decide`, `Auto`, `BuildTable`, `BuildTree`, `BuildChart`): inspector, table, cards (`Table.AlwaysCards`), tree, chart, code or text by the shape of the data; presenters by member name and type (`CellPresenters.ForMember`, `StatusEnumPresenter`); `-View Grid` opens the interactive grid.
- Opt-in default formatting: `Enable-ConsoleFormatting` / `Disable-ConsoleFormatting` (a session Out-Default function over `Out-ConsoleDefault`) and `Register-ConsoleView`; files, processes and services built in; redirected output, pipelines, `Format-*`, `Out-String`, jobs and remoting are unaffected.
- Targets: `ITerminalTarget` with `ConsoleTarget`, `RecordingTarget` (`TestTerminal.Target`, `MatchGolden`), `WriterTarget` and `NullTarget`; `Terminal.Use(target)` scopes the static methods (async-local), `Terminal.DefaultTarget`, `LiveSessionOptions.Target`, `InteractiveOptions.Target` and `target.Write/WriteMarkupLine/Status` extensions; the `target` example shows the library pattern.
- Progress columns: `Lanes.Columns` and `ProgressBar.Columns` with `ProgressColumns` (Spinner, Description, Bar, Percent, Count, Elapsed, Remaining, Rate, ByteRate, Results, Status, Custom), smoothed rate and ETA over `RateWindow`, `HideCompleted`, `CollapseWhenFinished`, `Transient`, priority-based column dropping and column summaries in the stream heartbeat; `-Column`, `-HideCompleted`, `-CollapseWhenFinished` and `-Transient` on the cmdlets.
- Built-in labels translated to Polish, German, Spanish, French and Italian (`PromptLabels.For`, `WidgetLabels`, `TerminalProfile.WithLanguage`, `CONSOLEMONSTER_LANGUAGE`), following the UI culture; `Table.TotalLabel` defaults to the translated word.
- Replaceable regions: `Slot`, `LiveSession.Region(name).Set(widget)`, `SlotHandle`, `DashboardBuilder.Region`, `New-ConsoleRegion` and `Set-ConsoleRegion`; swaps go through the update queue, keep the surrounding frame and register live widgets in the new content. `LiveEvent.Payload` carries in-process objects (not recorded).
- Keyed live tables: `LiveTable` with `LiveTableHandle.AddRow/UpdateRow/RemoveRow/Clear`, stable column widths, `MaxRows` (recent rows) and `SortColumn`; `New-ConsoleLiveTable` and `Update-ConsoleTable`; `Table.ClearRows`.
- Emoji and symbol fallback per glyph tier (`SymbolFallback`, extensible), applied to markup, rich text and table cells before measuring; opt-in `:shortcode:` emoji (`Markup.Shortcodes`, `Shortcodes`, the `Emoji` cell presenter).
- `Use-ConsoleTarget` (file, writer, target or string); PowerShell output follows a non-console target. The Pester view and the render-error frame are translated too.
- Spectre markup compatibility: the 256 xterm colour names (`[cadetblue]`, `[grey50]`, `[deepskyblue3]`, numbered duplicates such as `[blue3_1]`), `[link]url[/]` next to `[link=url]text[/]`, OSC 8 only for http, https, mailto and ftp targets (the exporters' filter, now applied to all terminal output), closed unknown tags removed with their text kept, `Markup.Strict` / `Markup.Parse(..., strict: true)` to throw instead, `Markup.Interpolate` for escaped arguments, and `EscapeMarkup()` / `RemoveMarkup()` string helpers. Colliding names follow one rule: in markup a name is the palette colour (`[darkred]` is palette 52), in `-Color` and ConsoleColor parameters it keeps the Write-Host meaning (`grey` spells Gray); `console.<name>` and `palette.<name>` ask for either meaning in both places.
- `Terminal.WriteMarkup` no longer ends the line (Spectre's `Markup`); `Terminal.WriteMarkupLine` does. `Write-ConsoleMarkup -NoNewLine`.
- `Terminal.Status` / `Terminal.StatusAsync`: a one-call spinner status with `ctx.Update(...)`, removed when the work ends, plain lines in redirected and CI output.
- `Terminal.Clear()`, `Terminal.HideCursor()` / `ShowCursor()` (restored on exit and Ctrl+C) and `Clear-ConsoleScreen`, no-ops in redirected and CI output.
- `ROADMAP.md` (decisions, next rounds, backlog) and the one-version policy for products in the README.
- `Write-ConsoleText -LogFile` keeps an existing log's encoding (byte order mark, or UTF-16 text without one), so Write-Color's UTF-16 logs stay UTF-16; a contradicting `-Encoding` warns. `ConsoleLogFile.DetectEncoding`, `KeepExistingEncoding`, `EncodingSpecified`.
### 2.0.0 - prototype (unreleased)
#### What's new
- Rebuilt as a zero-dependency .NET library (netstandard2.0, net472, net8.0) plus a thin binary PowerShell module for Windows PowerShell 5.1 and PowerShell 7.
- Terminal capability detection with `CONSOLEMONSTER_COLOR`, `CONSOLEMONSTER_GLYPHS`, `CONSOLEMONSTER_MODE` and `NO_COLOR` overrides; Unicode-safe output through `WriteConsoleW`.
- Spectre-compatible markup, semantic themes (dark, light, high contrast) and Full/Basic/ASCII glyph tiers.
- Widgets: text, rule, panel, table, tree, key/value, status list, spinner, progress, lanes, phases, bar and stacked bar, sparkline, histogram, braille line/scatter chart, log region, logo and dashboard; layouts Rows, Columns, Grid, Padding, Align and Stack.
- Live sessions: thread-safe updates coalesced at about 15 frames per second, console and PowerShell stream capture, Ctrl+C restore, JSON-lines record and replay (the replayed clock follows the recorded timeline), optional `[mm:ss]` prefixes on stream-mode lines (on by default in CI).
- Bars come in `Line` (progress and lanes default) and `Block` (bar and stacked chart default) shapes.
- Table width negotiation: column priority, minimum and maximum widths, overflow (wrap with a line limit, truncate, middle truncation, never), hidden-column footer, stable widths in live tables; record cards below a configurable width and a record view for single records.
- Groups with subtotals, totals (sum, count, average, minimum, maximum) and "Showing N of M" top-N.
- Cell presenters shared by tables, cards, key/value lists and trees: status, number, bytes, duration, date (absolute, relative, both; time zone), boolean, in-cell data bar, sparkline and progress, OSC 8 links; tone rules by threshold; readable without colour.
- Object inspector for .NET objects, PSObjects, dictionaries and `JsonElement` (net8.0) with depth and item limits, cycle detection, include/exclude and ordering; reflection isolated in one member source.
- `Format-ConsoleTable`, `Format-ConsoleList` and `Format-ConsoleTree`: Format-Table style `-Property` (calculated properties, column option hashtables), DefaultDisplayPropertySet, `-GroupBy`, `-Total`, `-Top`, `-Width`, `-PassThru`.
- Live sessions handle window resizes (full redraw, coalesced while dragging), viewport scrolling, font changes (conhost font polling, width re-probe after Windows Terminal resizes) and windows that are too small (reduced layout by panel priority, then a one-line status).
- Light/dark background detection in conhost and `CONSOLEMONSTER_THEME=light|dark|auto`.
- Wrapping breaks after spaces, then after separators (path, list and query separators before dots, dashes and colons), then by character; `LogRegion.Wrap` wraps long log entries.
- Explicit culture for numbers and dates: `CONSOLEMONSTER_CULTURE`, `TerminalProfile.WithCulture`, `LiveSessionOptions.Culture` and `-Culture` on the Format cmdlets (default: the current culture).
- Outside a real local console (jobs, remoting, SSH, the ISE, redirected output, transcripts) cmdlets write through the PowerShell host like Write-Host, so jobs complete, transcripts record and `6>&1` captures the output.
- Host output keeps colour: coloured host UI writes on a real console with a transcript and in the ISE (plain lines in the transcript), coloured Write-Host-style records in jobs and remoting; redirected output stays plain.
- Rich text: multicolour spans (ConsoleColors exactly as Write-Host shows them, theme roles, hex/RGB, decorations, links, gradients) accepted in every widget, safe by default (data stays literal), with `RichText`/`RichTextBuilder` in C# and `New-ConsoleText` in PowerShell.
- `Write-ConsoleText` with Write-Color parameter parity plus markup, styles, gradients, padding, wrapping, split lines and Text/CSV/JSON-lines logs; `Write-ConsoleStatus` for an updating status line.
- Print-once output reads the window size on every write.
- Sentinel dates show as "never" and unbounded durations or non-finite numbers as a dash, instead of throwing; charts skip non-finite values.
- Stream and plain output sanitise escape sequences and control characters.
- Dashboards report unknown widget names, failed updates, failed frames and early ends through the host; `LiveSession.GetCounters()`; a dashboard that cannot start leaves the screen untouched.
- The object inspector has a node budget (`MaxNodes`, `-MaxNodes`), skips blocking getters and lets Ctrl+C through.
- Input core: Windows console keys through `ReadConsoleInputW` (Ctrl/Alt combinations, Shift+Tab, function keys, AltGr, pastes, resizes, focus), VT input decoding, scripted input for tests and demos, and one keyboard owner shared by prompts and live sessions.
- Prompts: confirm (with typed confirmation), text, secret, number, selection, multi-selection and path, with fuzzy filtering, groups, hotkeys, badges, previews, inline validation, typed results, line-based and accessible fallbacks, and defaults or a clear error when nobody can answer.
- Forms and wizards: pages with a progress strip, conditional and dependent fields with async loading, a review page with the equivalent command line, named presets and opt-in remembered choices.
- Menus and the app shell: Shell, Classic and Inline layouts, breadcrumb navigation, a command palette with providers, a key map and footer generated from the active keys, toasts, prompts over the app, and runs into a live dashboard that return to a results summary.
- Menu actions: console output, Write-Host, warnings and errors are collected and shown as a toast or an output dialog instead of drawing over the app; async actions ask through the menu's thread; a blocked Run shows its problem count and opens the item that fixes it; leaving a form with unsaved changes asks to discard them.
- Export: widgets, rendered frames and live-session snapshots to self-contained HTML (light and dark), SVG (box, block and braille drawn as shapes) and text; recordings to an HTML player, an animated SVG and asciicast v3 (ConsoleExporter, Recording, Export-ConsoleFrame, Export-ConsoleRecording, Format-ConsoleTable -AsWidget); ScreenCapture draws interactive screens into memory.
- Inline live area (`LiveSessionOptions.Mode = Inline`, `Start-ConsoleDashboard -Inline`/`-Transient`): a live region below the cursor with output scrolling above it; stream lines in CI and redirected output.
- `Write-Progress` from dashboard runspaces shows as nested activities (`ActivityList`); `Use-ConsoleProgress` renders a script's `Write-Progress` inline.
- Public test helpers: `TestTerminal`, `GoldenFile` (`CONSOLEMONSTER_UPDATE_GOLDEN=1`, readable diffs), `ScreenCapture` and `Assert-ConsoleOutput`.
- Long tables print in blocks (`Terminal.StreamingRowThreshold`, `Terminal.RenderChunks`): 50,000 rows use about 76 MB instead of 510 MB.
- SVG exports batch shapes into one path per colour; `ExportOptions.Elapsed` sets the clock of widget exports; `Format-ConsoleTable -AsWidget` keeps `-Culture` (`CultureScope`).
- A Windows CI workflow runs xUnit (net472, net8.0) and Pester (5.1, 7).
- Design system (`Docs/Design-System.md`): shared `HeaderBar`, `FooterBar`, `DialogChrome`, status symbols and spinner. Runs from menus and forms (`FormOptions.AfterSubmit`) stay in the same frame, and Write-Host colours are kept above inline areas and in log regions.
- `Invoke-ConsolePester`: Pester 5 and 6 runs with a live dashboard (inline or full screen), a summary table by file, `-ExportHtml`, stream lines in CI, and Pester's result object; built on the new `TestRun`/`TestRunView`/`TestRunSummary` widgets. One-shot console writes go above a running inline area, and `LiveSessionOptions.Discoverable` keeps a session out of `LiveSession.Current`.
- Menu icons follow the glyph tier: `GlyphIcon` names (`WithIcon(GlyphIcon.Targets)`, `-IconName`) with Full, Basic and ASCII forms. `Lanes.CountSkipped` and `Histogram.EdgeFormat` added.
- `ExceptionView`, `Format-ConsoleError` and `Write-ConsoleException`: readable exceptions and ErrorRecords with source lines, script stacks, collapsed framework frames and inner errors.
- A dependency-free highlighting engine (`ITextHighlighter`, `Highlighters`, `RegexHighlighter`, smart values) with `CodeView`, `Format-ConsoleCode`, `Format-ConsoleJson`, `Write-ConsoleLog -Highlight` and the `Highlight` table column option.
- `TextAreaPrompt` and `TextAreaField` (`Read-ConsoleText -Multiline`, `New-ConsoleField -Type TextArea`) for multi-line text.
- `Grid` and `Show-ConsoleGrid`: an interactive table viewer with filter, sort, marks, column chooser and details.
- Clipped text in test runs and stat columns ends with the tier's ellipsis.
- Cmdlets with a plain `Console` noun (see `Get-Command -Module ConsoleMonster`) (`Write-ConsoleTable`, `Format-ConsoleTable`, `New-ConsoleDashboard`, `Start-ConsoleDashboard`, `Read-ConsoleSelection`, `Show-ConsoleMenu`, `Read-ConsoleForm`, ...).
