### 2.1.3 - 2026-11-04

Apps get screens, scoped key bindings and an overlay layer, and can be tested and driven without a terminal. Images draw inline, summary commands get dashboard frames, and diagrams arrive in the core with routed topology rendering in Graphics.

#### Public API (breaking changes)
I consolidated the pre-launch API: commands and builders that did the same job became one, leaving 89 exported cmdlets, and Commander and file operations moved to `ConsoleMonster.CLI`, outside the module and the library packages. (#91)

- Constructors return reusable widgets; `Show-Console` and `Show-ConsoleTable` display them. Records use `Show-Console -View List`, static inspectors use `Show-Console -View Tree`, and explicit hierarchies use `New-ConsoleTree`. `Show-ConsoleObject` is a rich interactive explorer.
- `New-ConsoleTable` owns table configuration through `-Property`. Charts and rules are built with `New-ConsoleChart` and `New-ConsoleRule`, then displayed with `Show-Console`. `Export-ConsoleFrame` accepts objects or widgets and returns text when no path is supplied.
- Live addresses use `WidgetId`, stored identities use `Key`, visible item text uses `Label`, and view headings use `Title`. Semantic styling uses `Role`, literal colors use `Color`/`BackgroundColor`, and text decoration uses `Decoration`.
- Item collections, tabs, menu results and numeric-column formats accept records in their parent definitions. `New-ConsoleStatusList -Layout Strip` builds phase strips; `New-ConsoleRegion` handles alignment and padding. Dashboard and app parameters configure headings and footers.
- `Update-Console` validates live updates. Custom C# targets receive events through `LiveSession.Post`. `Compare-ConsoleObject -Question` displays changes and returns the confirmation decision.
- `Enable-ConsoleFormatting` enables Output, FormatCommands, Errors, Streams and ReadLine by default. `-Include` and `-Exclude` adjust that set; `-ErrorLayout Compact|Standard|Detailed` selects error detail. Prompt, Help, Progress and GridView remain opt-in. `Get-ConsoleFormatting` reports the active features.
- Interactive snapshots use `-Mode Snapshot`. `Show-ConsolePresentation -ScriptPath` selects a demo script and optional `-Path` records it unattended; `Get-ConsoleDemo` exposes standalone script text through `.Source`. Recording exports read the cast from `-RecordingPath` and write to `-Path`; frame exports and session recording also use `-Path`. `-ChromeStyle None|MacOS|Windows|Linux` selects window decoration.
- The PowerShell module ships net472 and net8.0 payloads and bundles the Markdown and graphics add-ons. NuGet packages retain their existing target frameworks. Commander and file-operation application code live in `ConsoleMonster.CLI`, outside the library packages and module.
- Imports register only the documented allowlist of fully qualified type accelerators. Markdown display and export belong to `ConsoleMonster.Markdown`; the rendering core stays dependency-free.

#### What's new
- Images inline: `Show-ConsoleImage -Path ./chart.png -Width 40` draws real pixels in Kitty and Ghostty (Kitty graphics), iTerm2 and WezTerm (iTerm2 inline images) and Windows Terminal (Sixel), half blocks on any other terminal with 256 colours or more, and `[image: name WxH]` in redirected, CI and no-colour output. `New-ConsoleImage` places an image inside panels and dashboards, and `ConsoleImage` in `ConsoleMonster.Graphics` takes PNG bytes, a file or a ChartForgeX render. `Get-ConsoleCapability` reports the protocol in `ImageProtocol`. See [Inline images](https://consolemonster.dev/docs/inline-images/).
- Apps can have screens without hand-wiring them. Adjacent `New-ConsoleScreen` commands (`AppScreens` in C#) make a screen stack with back navigation on Escape and Backspace, inputs inside screens, focus kept per screen and breadcrumbs in the header. Keys are declared once per input, screen or app (`-KeyBinding`, `KeyBinding`), and the footer is built from them, so it never lists a key that does nothing. `'1-12'` and `KeyBinding.Numbered` open numbered items, including two-digit numbers, and letter and digit keys work on other keyboard layouts. Dropdowns (`New-ConsoleSelect -Dropdown`), dialogs and toasts draw on an overlay layer above the content. `Show-ConsoleApp -KeyBinding` replaces `-FooterHints` and `-HandleInput`. Output written while an app runs goes into the app instead of below its footer, panels shrink with their borders in a short window, the command palette has one frame, and the debug socket's `tree` reports why each control has its size (protocol 2). See [Interactive applications](Docs/Interactive-Apps.md#screens-keys-and-the-overlay-layer).
- Your text is never rewritten: on the Basic and ASCII glyph tiers (conhost, redirected files, CI logs) only ConsoleMonster's own borders, markers, spinners and icons fall back, while labels, table cells and log lines keep their emoji and symbols. Redirected output (files, pipes, CI logs) is as wide as `COLUMNS` when it is set, through one width rule that every PowerShell command and `Get-ConsoleCapability` share. Output that cannot make links clickable prints `text (url)`.
- Apps can be tested, recorded and driven like web pages. `HeadlessTerminal` runs the full app with no terminal (scripted keys, clicks and resizes in, the composed screen out) behind the new `IConsoleDriver` seam, which the console also implements. `Invoke-ConsoleRecording -Headless -InputScript` and `LiveSessionOptions.Recorder` record what the user saw, including the log panel, footer and dialogs, and captured screens export to GIF, APNG, animated SVG and the HTML player. `BrowserHost` shows a headless app in a self-contained local page that sends keys and clicks back, and the opt-in `DebugSocket` (localhost only, token, secrets masked) lets agents read the screen and control tree and send input. See [the headless driver guide](Docs/Headless-Driver.md).
- Log panels are app-grade log tails. - Spectre markup compatibility: the 256 xterm colour names (`[cadetblue]`, `[grey50]`, `[deepskyblue3]`, numbered duplicates such as `[blue3_1]`), `[link]url[/]` next to `[link=url]text[/]`, OSC 8 only for http, https, mailto and ftp targets (the exporters' filter, now applied to all terminal output), closed unknown tags removed with their text kept, `Markup.Strict` / `Markup.Parse(..., strict: true)` to throw instead, `Markup.Interpolate` for escaped arguments, and `EscapeMarkup()` / `RemoveMarkup()` string helpers. Colliding names follow one rule: in markup a name is the palette colour (`[darkred]` is palette 52), in `-Color` and ConsoleColor parameters it keeps the Write-Host meaning (`grey` spells Gray); `console.<name>` and `palette.<name>` ask for either meaning in both places.
- `Terminal.WriteMarkup` no longer ends the line (Spectre's `Markup`); `Terminal.WriteMarkupLine` does. `Write-ConsoleText -Markup -NoNewLine`.
- `Terminal.Status` / `Terminal.StatusAsync`: a one-call spinner status with `ctx.Update(...)`, removed when the work ends, plain lines in redirected and CI output.
- `Terminal.Clear()`, `Terminal.HideCursor()` / `ShowCursor()` (restored on exit and Ctrl+C), no-ops in redirected and CI output.
- `ROADMAP.md` (decisions, next rounds, backlog) and the one-version policy for products in the README.
- `Write-ConsoleText -LogFile` keeps an existing log's encoding (byte order mark, or UTF-16 text without one), so Write-Color's UTF-16 logs stay UTF-16; a contradicting `-Encoding` warns. `ConsoleLogFile.DetectEncoding`, `KeepExistingEncoding`, `EncodingSpecified`.

#### What's new
- Rebuilt as a zero-dependency .NET library (netstandard2.0, net472, net8.0) plus a thin binary PowerShell module for Windows PowerShell 5.1 and PowerShell 7.
- Terminal capability detection with `CONSOLEMONSTER_COLOR`, `CONSOLEMONSTER_GLYPHS`, `CONSOLEMONSTER_MODE` and `NO_COLOR` overrides; Unicode-safe output through `WriteConsoleW`.

- Live sessions: thread-safe updates coalesced at about 15 frames per second, console and PowerShell stream capture, Ctrl+C restore, JSON-lines record and replay (the replayed clock follows the recorded timeline), optional `[mm:ss]` prefixes on stream-mode lines (on by default in CI).
- Bars come in `Line` (progress and lanes default) and `Block` (bar and stacked chart default) shapes.
- Table width negotiation: column priority, minimum and maximum widths, overflow (wrap with a line limit, truncate, middle truncation, never), hidden-column footer, stable widths in live tables; record cards below a configurable width and a record view for single records.

- Cell presenters shared by tables, cards, key/value lists and trees: status, number, bytes, duration, date (absolute, relative, both; time zone), boolean, in-cell data bar, sparkline and progress, OSC 8 links; tone rules by threshold; readable without colour.

- `Show-ConsoleTable`, `Show-Console -View List` and `Show-ConsoleTree`: Format-Table style `-Property` (calculated properties, column option hashtables), DefaultDisplayPropertySet, `-GroupBy`, `-Total`, `-Top`, `-Width`, `-PassThru`.

- Light/dark background detection in conhost and `CONSOLEMONSTER_THEME=light|dark|auto`.
- Wrapping breaks after spaces, then after separators (path, list and query separators before dots, dashes and colons), then by character; `LogRegion.Wrap` wraps long log entries.
- Explicit culture for numbers and dates: `CONSOLEMONSTER_CULTURE`, `TerminalProfile.WithCulture`, `LiveSessionOptions.Culture` and `-Culture` on the Format cmdlets (default: the current culture).
- Outside a real local console (jobs, remoting, SSH, the ISE, redirected output, transcripts) cmdlets write through the PowerShell host like Write-Host, so jobs complete, transcripts record and `6>&1` captures the output.
- Host output keeps colour: coloured host UI writes on a real console with a transcript and in the ISE (plain lines in the transcript), coloured Write-Host-style records in jobs and remoting; redirected output stays plain.
- Rich text: multicolour spans (ConsoleColors exactly as Write-Host shows them, theme roles, hex/RGB, decorations, links, gradients) accepted in every widget, safe by default (data stays literal), with `RichText`/`RichTextBuilder` in C# and `New-ConsoleText` in PowerShell.
- `Write-ConsoleText` with Write-Color parameter parity plus markup, styles, gradients, padding, wrapping, split lines and Text/CSV/JSON-lines logs; `Show-ConsoleStatusLine` for an updating status line.
- Print-once output reads the window size on every write.
- Sentinel dates show as "never" and unbounded durations or non-finite numbers as a dash, instead of throwing; charts skip non-finite values.
- Stream and plain output sanitise escape sequences and control characters.
- Dashboards report unknown widget names, failed updates, failed frames and early ends through the host; `LiveSession.GetCounters()`; a dashboard that cannot start leaves the screen untouched.
- The object inspector has a node budget (`MaxNodes`, `-MaxNodes`), skips blocking getters and lets Ctrl+C through.
- Input core: Windows console keys through `ReadConsoleInputW` (Ctrl/Alt combinations, Shift+Tab, function keys, AltGr, pastes, resizes, focus), VT input decoding, scripted input for tests and demos, and one keyboard owner shared by prompts and live sessions.
- Prompts: confirm (with typed confirmation), text, secret, number, selection, multi-selection and path, with fuzzy filtering, groups, hotkeys, badges, previews, inline validation, typed results, line-based and accessible fallbacks, and defaults or a clear error when nobody can answer.
