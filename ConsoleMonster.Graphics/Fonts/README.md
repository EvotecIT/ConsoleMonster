JetBrainsMono.ttf is the unmodified JetBrains Mono Regular font from the
[JetBrains Mono project](https://github.com/JetBrains/JetBrainsMono/blob/master/fonts/ttf/JetBrainsMono-Regular.ttf).
It includes the full upstream character set rather than the website's Latin subset.
The SIL Open Font License and copyright notice are in OFL.txt and are also
included in the NuGet package and the PowerShell module's Notices directory.
