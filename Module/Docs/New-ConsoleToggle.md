# New-ConsoleToggle
## SYNOPSIS
Creates a named Boolean toggle for Show-ConsoleApp.

Emits a stable core Toggle widget. Place inputs in the outer layout, outside dependent bindings. The final state contains the input's committed value.

## SYNTAX
### __AllParameterSets
```powershell
New-ConsoleToggle [-Key] <string> [[-Label] <string>] [-Value <bool>] [-OnText <string>] [-OffText <string>] [-Disabled] [-TabIndex <int>] [-OnChange <scriptblock>] [-ValidationMessage <string>] [<CommonParameters>]
```

## DESCRIPTION
Creates a named Boolean toggle for Show-ConsoleApp.

Emits a stable core Toggle widget. Place inputs in the outer layout, outside dependent bindings. The final state contains the input's committed value.

## EXAMPLES

### EXAMPLE 1
```powershell
New-ConsoleToggle -Key Enabled -Label 'Enable checks' -Value $true
```

Create an application input.
