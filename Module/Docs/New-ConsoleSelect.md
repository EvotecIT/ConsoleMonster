# New-ConsoleSelect
## SYNOPSIS
Creates a named select input for Show-ConsoleApp.

Choices use the shared prompt conversion and retain original objects as values. Keep the input in the stable outer layout. Disabled choices cannot be selected.

## SYNTAX
### __AllParameterSets
```powershell
New-ConsoleSelect [-Key] <string> [[-Label] <string>] -Choices <Object[]> [-Value <Object>] [-Multiple] [-Radio] [-Dropdown] [-PageSize <Int32>] [-Display <Object>] [-Disabled] [-TabIndex <int>] [-OnChange <scriptblock>] [-ValidationMessage <string>] [<CommonParameters>]
```

## DESCRIPTION
Creates a named select input for Show-ConsoleApp.

Choices use the shared prompt conversion and retain original objects as values. Keep the input in the stable outer layout. Disabled choices cannot be selected.

## EXAMPLES

### EXAMPLE 1
```powershell
New-ConsoleSelect -Key Environment -Choices 'Production', 'Staging' -Value Staging
```

Choose initial values.
