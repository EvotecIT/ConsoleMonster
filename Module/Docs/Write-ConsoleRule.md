# Write-ConsoleRule
## SYNOPSIS
Writes a horizontal rule, optionally with a title.

A quick section separator for scripts.

## SYNTAX
### __AllParameterSets


## DESCRIPTION
Writes a horizontal rule, optionally with a title.

A quick section separator for scripts.
