# New-ConsoleFlowEdge
## SYNOPSIS
Creates a labelled connection between adjacent flow nodes.

## SYNTAX
### __AllParameterSets
```powershell
New-ConsoleFlowEdge -Key <string> -From <string> -To <string> [-Label <string>] [-Status <StatusKind>] [-Cut] [<CommonParameters>]
```

## DESCRIPTION
Creates a labelled connection between adjacent flow nodes.

## EXAMPLES

### EXAMPLE 1
```powershell
New-ConsoleFlowEdge -Key tls -From client -To host -Label 'TLS 1.3' -Status Pass
```
