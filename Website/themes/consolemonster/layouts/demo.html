Run it yourself

Three steps in PowerShell, four in C#. Every command copies with one click.

  1. Install the module

    Once. Windows PowerShell 5.1 or PowerShell 7 on Windows, macOS or Linux.

    {{~ cmd_lang = "powershell"; cmd_text = "Install-Module ConsoleMonster -Scope CurrentUser" ~}}{{ include "command" }}

  2. Save the program

    Download it, or copy it from above into {{ ps_file }}.

    {{~ if d.powershellDownload ~}}Download {{ ps_file }}{{~ end ~}} {{~ if ps && ps.repo ~}}View on GitHub{{~ end ~}}

  3. Run it

    From the folder you saved it in.

    {{~ cmd_lang = "powershell"; cmd_text = "./" + ps_file ~}}{{ include "command" }}

  1. Create a project

    A plain console app; .NET 8 or later.

    {{~ cmd_lang = "bash"; cmd_text = "dotnet new console -n " + project + " && cd " + project ~}}{{ include "command" }}

  2. Add ConsoleMonster

    The only package the program needs.

    {{~ cmd_lang = "bash"; cmd_text = "dotnet add package ConsoleMonster" ~}}{{ include "command" }}

  3. Replace Program.cs

    Download it, or copy the program from above.

    {{~ if d.csharpDownload ~}}Download Program.cs{{~ end ~}} {{~ if cs && cs.repo ~}}View on GitHub{{~ end ~}}

  4. Run it

    {{~ cmd_lang = "bash"; cmd_text = "dotnet run" ~}}{{ include "command" }}

Or skip the copying. Every demo ships with the module and the project template.
