Each table below has PowerShell, C# initializer and C# fluent tabs. Its frame is printed by the complete C# program shown with it, run at 120, 100, 80, 64, 48 and 36 columns. The data is invented, and the programs that show relative dates fix the time they measure from, so those read the same every day. From PowerShell, `Show-ConsoleTable`, `Show-Console -View List` and `Show-Console -View Tree` build the same widgets from pipeline input; the [PowerShell page](/powershell/) shows them beside `Format-Table`.
